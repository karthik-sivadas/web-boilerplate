# Contributing

1. Use Node 24.13.1 and pnpm 11.7.0.
2. Install with `pnpm install --frozen-lockfile`.
3. Start from the feature task template for user-visible work.
4. Run `pnpm verify` before opening a pull request.

Keep changes small, include accessible error and empty states where applicable, and avoid unrelated dependency upgrades. This repository has no automatic release or agent publication workflow.
