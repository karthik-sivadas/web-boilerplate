# PostgreSQL verification map and limits

`pnpm verify` is the required full local gate: formatting, lint/import-boundary consumer fixtures, types, root coverage, real PostgreSQL API tests, both builds, copied source-free artifacts, `test:ssr` shared-lifetime/disconnect checks and desktop/mobile browser tests. `pnpm test:docker` is an additional CI gate using its own random Compose project/volume. Release claims require the final executed logs and independent supervisor review, not this inventory alone.

Final repair regressions additionally cover same-session read/mutation ordering with mounted deferred responses; static-template/computed-import/barrel/alias boundary bypasses; exact reviewed CI action SHAs/runner/permissions; and secret/password roundtrips through both dotenv and actual Node `--env-file`, including immutable existing-file handling. `test:ssr` runs a copied real Nitro/Start artifact against a delayed HTTP dependency: two eight-second readiness/identity stages must share one 15-second budget, and disconnect after readiness must cancel the identity HTTP request.

The offline SQLite auth importer and its tests were intentionally retired; they are no longer current capability evidence. Published migration 004 remains historical checksum evidence, not importer support.

Old browser persistence **writing/reset/memory-fallback** tests are not blindly preserved: those behaviors were intentionally removed. Their safety properties are mapped to explicit preservation and remote uncertainty tests above. No user data was migrated by implementation tests.

## SQLite-removal local evidence

Executed on the uncommitted SQLite-removal change: `pnpm verify` passed with **86 root tests / 13 files**, **25 real-PG API tests / 6 files**, and **24 browser executions**, plus copied-artifact and SSR lifetime/disconnect checks. Root coverage: 96.33% statements, 92.30% branches, 92.68% functions, 98.15% lines. The retired importer tests are not included. Owned Docker smoke passed, including absence of importer delivery. A forced full build with no database URLs or auth secrets also passed. Development PostgreSQL was not migrated; supervisor application of 005 and independent review remain required.

## Evidence limitations

Root coverage measures the selected core/auth/session/client/legacy-reader layers, not every rendered component. API coverage does not instrument child artifact processes; child/Docker/browser executions provide functional evidence separately. The RTL fixture is presentation evidence, not real backend security evidence. Desktop/mobile Chromium emulation does not prove every physical device or browser engine. Local HTTP and synthetic HTTPS-origin cookie tests do not certify a hosted TLS proxy. Native Windows shutdown, hosted rollout, production restore/retention, mail ownership/recovery and independent final security review remain separate operational acceptance concerns. Application import rollback is not a general migration rollback.
