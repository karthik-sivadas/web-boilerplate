# Production readiness matrix

Workbench is a credential-free browser demo. It is useful for exploring the UI and local state model; it is **not** a production certification, account system, cloud sync service, backup, or security boundary. “Built” means present in this repository, not independently certified at a deployment target.

## Verification boundaries

Local checks can demonstrate source behavior, production builds, and browser tests against a local Node artifact. GitHub Actions is expected to demonstrate the pinned hosted runner, installed browser, and Docker container browser smoke. A deployment target must separately verify DNS, TLS, proxy configuration, secrets, monitoring, data controls, and release/rollback practices.

The current CSP uses `unsafe-inline` for Start hydration/styles and is not described as strict. It must be hardened or explicitly risk-accepted before sensitive deployment. Dependency audit evidence is time-sensitive: the supervisor’s latest report recorded no moderate/high/critical findings and one low Windows-development-server `esbuild` advisory (`GHSA-g7r4-m6w7-qqqr`, affected `>=0.27.3 <0.28.1`, patched in `0.28.1`); this repository does not override package versions outside its approved dependency workflow.
